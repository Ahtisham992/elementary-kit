# Submission Checklist

Use this right before submitting — every item maps to an actual qualification or judging criterion.

## Qualification (required)
- [ ] Repo is public
- [ ] Complete source code included (no missing files/private deps)
- [ ] Starred the Elements repo (https://github.com/unlayer/elements)
- [ ] README explains the project
- [ ] README explains how to run it
- [ ] README includes a screenshot or GIF of rendered output
- [ ] Elements is genuinely core to the project (not just imported)

## Submission steps
- [ ] Submitted via official form: https://lnkd.in/e4RzksMV
- [ ] Posted publicly with **#BuiltWithElements**
- [ ] Tagged **Unlayer (YC W22)** in the post

## Quality pass (to maximize judging score)
- [ ] All 3 surfaces (email/web/PDF) render correctly
- [ ] Theme switcher works and visibly changes all 3 surfaces
- [ ] No console errors / render exceptions
- [ ] Demo GIF clearly shows the "one tree, many surfaces" idea in under 20 seconds
- [ ] README is skimmable in under 60 seconds by a judge
- [ ] Repo has a LICENSE file
- [ ] Commit history looks like real, incremental work (not one giant commit)

## Nice-to-haves if time allows
- [ ] Deployed demo link (Vercel/Netlify) so judges don't need to run it locally
- [x] Short write-up of one interesting technical challenge you solved
