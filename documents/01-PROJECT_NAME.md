# Project Name

## Elementary Kit

**Tagline:** *One component tree. Every surface.*

## Why this name

- Directly plays on "**Elements**" (the library this project is built with) — instantly signals what it is to anyone browsing GitHub or the #BuiltWithElements tag.
- "Elementary" also hints at the core idea: reducing content creation to its most fundamental building blocks — one shared design system, multiple output surfaces.
- Short, memorable, easy to say out loud in a demo video or GIF caption.

## One-line pitch

> Elementary Kit is a themeable onboarding content system — a welcome email, a landing page, and a PDF receipt — all rendered from the *same* React component tree using Unlayer Elements, with a live theme switcher to prove it isn't a one-off template.

## Repo name suggestion

`elementary-kit` (or `elementary-kit-elements` if the plain name is taken)
