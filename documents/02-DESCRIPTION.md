# Project Description

## What it is

Elementary Kit is an **onboarding content system** built entirely with Unlayer Elements. It demonstrates the "write once, render anywhere" promise of the library by using the exact same set of React components to produce three completely different outputs:

1. **A welcome email** — sent to a new user after signup, rendered as Outlook-safe table HTML.
2. **A landing/thank-you page** — the web version of the same content, rendered as responsive flexbox HTML.
3. **A PDF receipt/invoice** — a print-ready document version of the same brand content.

On top of that, the kit includes a **live theme switcher** with at least three themes (e.g. SaaS, E-commerce, Dark Mode). Switching themes re-skins all three outputs simultaneously — proving the design system, not just the copy, is shared across surfaces.

## Why it matters (the problem it solves)

Most teams maintain separate codebases for transactional emails, web pages, and PDF documents, even when the content and branding should stay consistent. Elementary Kit is a small, concrete proof that a single component tree can serve all three needs — cutting duplicated work and design drift.

## Who it's for

- Developers evaluating Elements for their own SaaS onboarding flows.
- Teams that currently hand-code emails separately from web pages and documents.
- Anyone who wants a copy-pasteable starting point for a themeable content system.

## What makes it stand out

- Covers **all three render modes** in one cohesive project (most submissions will likely cover only one).
- Includes a **working theme system**, not just static styling.
- Ships with **clear documentation and a demo GIF**, making it easy for judges to evaluate quickly.
