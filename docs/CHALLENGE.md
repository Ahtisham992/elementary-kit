# Challenge Details

Source: Unlayer (YC W22) LinkedIn post — "Build with Elements Challenge"

## Prizes

- 3 winners, $200 each
- Total pool: $600

## Deadline

- **July 31, 2026**

## How to participate

1. Build an original email or document template using Elements.
2. Publish it in a **public GitHub repository** with a clear README.
3. Submit via the official form: https://lnkd.in/e4RzksMV
4. Share publicly using **#BuiltWithElements** and tag **Unlayer (YC W22)**.

## Qualification requirements

- Elements must be a **core part** of the project (not just imported and unused).
- Star the Elements GitHub repository.
- Repo must be public with complete source code.
- README must explain the project, how to run it, and include a screenshot or GIF of the rendered output.
- No cap on number of submissions per builder.

## Judging criteria

- Originality
- Design quality
- Practical value
- Effective use of Elements
- Overall execution

## Bonus outcomes

- Standout submissions may be featured on Unlayer's channels / Elements showcase.
- Selected templates may be added to the official Unlayer template gallery.

## Our submission strategy against these criteria

| Criterion | How Elementary Kit addresses it |
|---|---|
| Originality | Multi-surface (email + web + PDF) kit with a live theme switcher — not a single static template |
| Design quality | Consistent, polished design system applied across all themes and surfaces |
| Practical value | Directly reusable for real SaaS onboarding flows |
| Effective use of Elements | Uses all three render modes (`Email`, `Body`/web, `Document`) from one shared tree |
| Execution | Clean repo, clear README, working demo GIF, tests for rendering output |
